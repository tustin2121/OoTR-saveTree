# Random discoveries
Random things I tested while making this save tree

- [01221A_ForestSongHookshotless](saves/01221A_ForestSongHookshotless) - If you go to forest temple before getting the hookshot, Shiek will again tell you to go get the hookshot in Kakariko. If you have the hookshot already, she will mention you have gotten it.
- [013010_GoronLink](saves/013010_GoronLink) - You don't have to exhaust the kid Goron's dialog to advance the plot. You can skip the first dialog option and go straight to the second.
- [017120_GuardDefeat1](saves/017120_GuardDefeat1) - Keys in Gerudo Fortress are "interchangeable" unlike the original. But also, if you try to unlock a cell with a key from another room, this just engages the carpenter in dialog as if you talked to the carpenter.
- [017400_SpiritSong](saves/017400_SpiritSong) - Shiek expresses gratitude for awakening Impa. What does she say when we complete spirit before Shadow?
- [017500_AdultSpiritStart](saves/017500_AdultSpiritStart) - LikeLikes don't steal your tunic anymore in this game. Which makes the tunics sold in the shops basically pointless.
